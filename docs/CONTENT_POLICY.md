# Content & Licensing Policy

## Goal

Use high-quality Dutch educational material while preserving provenance, attribution and licence obligations.

## Rules

1. **Free access is not the same as open reuse.** Every imported resource must store an explicit licence classification.
2. Resources with an unknown or incompatible licence are referenced by link/metadata only until reuse rights are verified.
3. Original LeerSprong NL content is marked `original` and versioned.
4. Creative Commons material must retain attribution and licence metadata required by its licence.
5. Share-alike content must not be silently relicensed.
6. Source URLs, provider, title and attribution must survive transformations and exports.
7. Generated educational material must be associated with the approved skill/curriculum target that constrained the generation.
8. Imported content is reviewed for age suitability, accuracy and accessibility before publication.
9. No third-party branding should imply endorsement of LeerSprong NL.
10. Admin tooling must support disabling a source/resource without deleting learner evidence already produced from historical sessions.

## Preferred source classes

- Official curriculum/open-data references such as SLO mappings.
- Open educational resources with clear Creative Commons/public-domain terms.
- Interactive activity engines with compatible open-source licences.
- External resources used as links when copying/repackaging rights are not confirmed.

## Required metadata

Each external learning resource should include:

```text
provider
title
canonical URL
licence classification
licence URL (when applicable)
attribution text (when applicable)
retrieved/imported timestamp
content version/checksum when locally stored
mapped curriculum skill IDs
review status
```

## AI-generated derivatives

AI must not be used to disguise copied copyrighted exercises as newly generated content. Generated tasks should be produced from abstract skill requirements and approved factual context, not from reproducing protected worksheets or books.
