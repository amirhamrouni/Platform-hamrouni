# Verhalenwereld — open-source references

LeerSprong's story text, characters and educational choices are original project content. The open-source projects below are used only as design/engine references.

## storytelling-engine-android

- Repository: https://github.com/michaldaniel/storytelling-engine-android
- License: MIT
- Relevant patterns: scene identifiers, chained scenes, character-driven story presentation and choice-based navigation.

## Arrow

- Repository: https://github.com/mhgolkar/Arrow
- License: MIT
- Relevant patterns: node-based nonlinear narrative, variables/state, branches and replayable paths.

## LeerSprong adaptation

The native Compose implementation uses small immutable story-node and choice models, group-aware original stories, vocabulary callouts, learning insights, alternate routes and replay. No third-party story text, characters, images or assets are copied.
