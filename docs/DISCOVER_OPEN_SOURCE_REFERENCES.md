# Ontdek de Wereld — open-source references

This feature uses interaction and architecture ideas from freely available open-source projects. No third-party lesson content, branding, maps, images or datasets are copied into LeerSprong NL.

## GeoLearnApp

- Repository: https://github.com/Ahtar1/GeoLearnApp
- License: MIT
- Relevant patterns: Android/Kotlin education app, Compose UI, Room-backed offline learning, multiple-choice, true/false and matching geography exercises.
- LeerSprong adaptation: short group-aware geography/science/history rounds and country-capital matching built with the existing native Compose stack.

## quizzity

- Repository: https://github.com/sharkdp/quizzity
- License: MIT
- Relevant patterns: fast geography rounds, score-driven discovery and location-oriented quiz pacing.
- LeerSprong adaptation: compact discovery rounds and immediate explanatory feedback. No map tiles, geodata or source code were copied.

## Licensing rule

MIT-licensed references may inform implementation patterns. Any future external datasets, map tiles, illustrations or question banks require a separate license and provenance check before inclusion in child-facing production content.
