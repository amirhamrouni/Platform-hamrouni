# Kunstlab — open-source reference

## Compose-Drawing-App

- Repository: https://github.com/SmartToolFactory/Compose-Drawing-App
- License: MIT
- Relevant patterns: Jetpack Compose Canvas drawing, touch gesture input, stroke/path history, erase/undo/redo concepts.
- LeerSprong adaptation: a child-focused Kunstlab with group-aware creative prompts, freehand drawing, a small curated color palette, undo, redo and clear.
- No third-party artwork, icons, branding or source files are bundled.

The implementation stays within LeerSprong's existing Compose stack and uses Android/Compose APIs directly.
