# LeerSprong NL Android 0.9.0-rc2

Release candidate 2 consolidates the source-backed learner-engine work completed after RC1.

## Included

- Native learner profile/onboarding for Groep 1–8.
- Offline-first Room evidence, XP, mastery, streak and review state.
- FSRS-based adaptive memory scheduling with non-destructive Room v1→v2 migration.
- Targeted relearning after mistakes.
- Native Listen & Choose with Dutch TextToSpeech.
- Accessible long-press ordering with arrow fallback.
- Groep-aware Home, Leerwereld and Voortgang.
- Expanded Groep 4 tracks: rekenen, Nederlands, Engels, Wereldoriëntatie, Burgerschap, Digitale geletterdheid, Kunst & Cultuur and NT2/Thuistaalhulp.
- Nederlands + Engels tracks for Groep 5–8.
- Deterministic RekenChallenge for Groep 2–8 with plausible distractors.
- WoordChallenge for Groep 4–8 with duplicate-safe per-letter spelling feedback.
- Local smart-review reminders based on actual learner evidence.
- Custom LeerSprong launcher icon, cleartext HTTP disabled and app backup disabled until an explicit learner-data backup policy exists.

## Source/tooling additions

- SLO curriculum snapshot/validation tooling pins official `slonl/curriculum-fo` source data to immutable commit SHAs and hashes.
- OpenTaal Dutch candidate-word-bank tooling pins and filters the permissively licensed source list for later pedagogical review.
- Third-party algorithms are attributed in project documentation; unverified-license repositories remain inspiration-only.

## Release gates

CI must pass Android unit tests, Android Lint, debug APK, release APK and release App Bundle builds before merge. The debug APK is installable for device testing. Release APK/AAB remain unsigned unless the four `LEERSPRONG_KEY*` signing environment variables are supplied from a permanent secure keystore.

## Not claimed complete

- Google Play publication/signing identity.
- Android Firebase Authentication/remote synchronization.
- Live AI backend for Maatje.
- Current production Web/Vercel deployment.

Those remain explicit release blockers rather than simulated features.
